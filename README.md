## Monitoring Stack for Linux and Windows Servers

This project provides a complete, containerized monitoring and observability stack designed to monitor both **Linux and Windows servers**.

It includes metrics collection, log aggregation, alerting, and automation capabilities using modern open-source tools, all orchestrated via **Docker Compose**.

### Key Features
- 📊 Metrics collection with **Prometheus**
- 📈 Visualization with **Grafana**
- 📜 Log aggregation using **Loki + Promtail**
- 🚨 Alerting via **Alertmanager**
- ⚙️ Automation and remediation support with **Rundeck**
- 🖥️ Cross-platform monitoring (Linux & Windows)
- 🐳 Fully containerized and reproducible setup

This stack is suitable for development, lab environments, and as a foundation for AIOps or enterprise monitoring systems.
